3. Recuperación desde GitHub

La aplicación obtiene el comprobante mediante:

  GET /api/admin/pedidos/:id/comprobante

La llamada requiere Authorization: Bearer <token> de administrador. El backend
consulta el archivo mediante GitHub Contents API, usando el nombre de archivo
que ya está guardado en pedido.comprobante. El token de GitHub permanece en el
backend. La respuesta binaria se entrega directamente a la aplicación; no se
envían al cliente URLs privadas de GitHub. Ante una ausencia en GitHub se
intenta leer UPLOADS_DIR/comprobantes; si falta en ambos lugares se responde
404.
